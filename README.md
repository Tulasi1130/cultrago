# 🌏 CulturaGo

**CulturaGo** is an interactive web project designed to help users explore the diverse culture of India through different states, destinations, traditional food, and cultural experiences.

The website presents Indian culture in a simple and engaging way, allowing users to discover different regions and learn more about their unique traditions, places, and cuisine.

## ✨ Features

* 🇮🇳 Explore different Indian states and their culture
* 📍 Discover notable places and destinations
* 🍛 Explore traditional and regional foods
* 🖼️ Image-based cultural exploration
* 🌐 Separate pages for different states
* 🎨 Simple and visually focused user interface
* 📱 Responsive web design

## 🗺️ States Covered

Currently, CulturaGo includes dedicated pages/content for:

* Telangana
* Karnataka
* Kerala
* Maharashtra
* Tamil Nadu

## 🛠️ Technologies Used

* **HTML5** — Website structure and individual state pages
* **CSS3** — Styling, layout, and responsive design
* **JavaScript** — Client-side interactions and functionality
* **Git & GitHub** — Version control and project hosting
* **GitHub Pages** — Website deployment

## 💻 Run Locally

1. Clone the repository:

```bash
git clone https://github.com/harshithakothi/cultrago.git
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No additional dependencies or installation are required.
